# Contributing to NÚ MAALE

Thank you for your interest in the NÚ MAALE initiative.

## Current project stage

The repository currently contains inception and requirements documentation. Software implementation is not authorized by the A1 baseline or by the initial repository documentation task.

Do not submit application code, infrastructure, deployment workflows, live integrations or participant data as if implementation were approved.

## Contribution principles

- Preserve A1-INIT-001 v1.0 as the first controlled inception baseline.
- Record new requirements as controlled addenda or proposed revisions.
- Keep Amharic-first and Ethiopian Calendar requirements visible in relevant proposals.
- Respect Maale language and cultural knowledge; seek competent community review.
- Do not include personal, confidential or sensitive participant information.
- Distinguish verified evidence, reported information, estimates and assumptions.
- Explain the purpose, scope, evidence and potential risks of each documentation change.

## Proposed documentation change process

1. Open an issue describing the proposed change and its rationale.
2. Identify whether it affects an existing controlled baseline.
3. Submit a focused pull request with supporting evidence.
4. Obtain the required Owner approval before treating a change as an approved project decision.

A contribution or pull request does not itself authorize implementation, expenditure, partnership commitments or deployment.
