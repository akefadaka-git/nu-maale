Record publicly verifiable government contact routes for requesting existing official administrative records. This document does not claim that any request has been sent or that any government office has supplied the requested records.

## 4. Records to request

Request existing records only:

1. Current, signed or officially certified Maale Woreda kebele register.
2. Official kebele names, unique administrative codes, rural/urban classification and effective dates.
3. Administrative boundary, merger, split, renaming and reclassification history.
4. Mapping of villages, settlements and local sections to current kebeles.
5. Current kebele count and the date on which that count became effective.
6. Population and household totals by kebele, with reference date, source and methodology.
7. Available aggregate population by age group and sex, including youth-age bands if already compiled and lawfully releasable.
8. Current health-post / health-centre catchment-to-kebele mapping, clearly distinguished from administrative boundaries.
9. ESS July 2026 Male-Wereda projection table, metadata, geographic codes and any relevant age/sex tables.

Ask the offices to state explicitly if a record does not exist, is held by another office, is restricted, or is available only in a different format.

## 5. Suggested request sequence

1. Contact the South Ethiopia Regional State Office of the President and request the official routing details for South Omo Zone Administration and Maale Woreda Administration.
2. Send the administrative-register request to Maale Woreda Administration, copying or separately addressing the Woreda Planning / Statistics Office once its official contact is confirmed.
3. Request zonal confirmation from South Omo Zone Administration.
4. Send the population projection and metadata request to ESS using its published contact details.
5. Log each request's date, recipient, delivery evidence, response date, document title, issuing authority, signature/seal, reference number and any restrictions.
6. Reconcile all received records against the 31 entries in A1-FRAME-001 without changing the source list. Record each match, non-match, alias, split, merger or unresolved item separately.

## 6. Suggested subject line

**Request for the Current Official Maale Woreda Kebele Register, Administrative Codes and Aggregate Population Records**

## 7. Authorization and privacy boundary

- This document records contact routes and a proposed request sequence only.
- No request has been sent by this addendum.
- No household-level or personally identifiable data is requested.
- Prefer administrative registers and aggregate statistics. If any office proposes disclosure of personal data, pause and assess legal basis, necessity, minimization and safeguards before proceeding.
- No field visits, interviews, enumeration, participant recruitment, expenditure, A2 reconciliation, A3 implementation or deployment is authorized by this record.

## 8. Closure dependency

The official-record verification remains OPEN until an authenticated current register and official code list are received and reconciled. A contact page, research paper, historical village list or population projection is not a substitute for that register.
