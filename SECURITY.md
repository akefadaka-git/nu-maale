# Security Policy

## Reporting a vulnerability

Do not publish exploitable vulnerability details, credentials, personal data or sensitive operational information in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository owner through a separately verified private channel and provide only the minimum information needed to establish contact.

## Scope

This repository is currently a documentation repository. No production application, service endpoint or deployed environment is declared here.

## Responsible disclosure

Allow the repository owner reasonable time to assess and coordinate remediation before public disclosure. Do not access, alter, exfiltrate or disrupt systems or data without explicit authorization.
